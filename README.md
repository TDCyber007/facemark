# FaceMark — Face Attendance System

FaceMark is a desktop face attendance system built with Python, CustomTkinter, OpenCV, and face recognition.

## Features
- Modern dark desktop interface
- Admin login
- Register people locally
- Live webcam face recognition
- Automatic daily attendance
- Attendance history and search
- Dashboard statistics
- Local SQLite database

## Tech Stack
- Python
- CustomTkinter
- OpenCV
- face_recognition
- SQLite
- Pillow

## How to Run
1. Create a virtual environment:
   python -m venv venv
2. Activate it:
   venv\Scripts\activate
3. Install dependencies:
   pip install -r requirements.txt
4. Run the application:
   python main.py

## Default Admin Login

## Privacy
Face encodings and attendance records are stored locally.
Do not upload face images, encodings, databases, or attendance CSV files to GitHub.
Use this application only with informed consent.
